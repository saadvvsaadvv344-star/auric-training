Saad's AIs learn here on GitHub's free computers (4 processor cores each, 6-hour runs that continue one after the other), so the PC's graphics card stays free. Without a graphics card it's slower: about 3–7 days for Auric v2 and 2–3 weeks for the image AI. Progress updates about every 20 minutes during a run.

Auric's own picture generator, built from zero: it learns to draw ~200 kinds of things (cat, car, tree…) from 49,074 real photos, 64×64. A separate judge checks if its pictures really show what was asked.
